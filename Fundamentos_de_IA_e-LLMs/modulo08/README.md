# MÓDULO 08

## O QUE SÃO MCPS (MODEL CONTEXT PROTOCOL) E COMO CONECTAM IA COM APIS/SERVIÇO

É um Protocolo que fornece habilidade de se comunicar com outros sistemas.
Padrão este que conecta os LLMs de IA diretamente nas fontes de dados. 
Padrão para plugar ferramentas de dados.


## Servidor MCP

Por padrão expoem 3 coisas:

* Lista de Ferramentas (tools)
  * São as ações que o agente pode fazer
* Lista de Resources ( Recursos)
  * São os dados para Contexto
* Lista de Prompts
  * Prompts prontos

A LLMs não ve o Servidor em si, mas sim a lista de ferramentas.
